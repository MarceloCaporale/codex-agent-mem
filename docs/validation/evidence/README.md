# Validation Evidence

This folder stores short public evidence notes for client/runtime claims. These
notes are summaries, not private logs. They avoid local paths, credentials, and
operational database contents.

Each note should include:

- date;
- operating system when relevant;
- client/runtime;
- MCP profile, mutability mode, and response mode;
- tools called;
- observed payload shape;
- caveats;
- result.
